طريقة إعداد صلاحيات HK LENS

1) ارفع ملف admin.html مكان ملف admin.html القديم في GitHub.

2) افتح Firebase Console:
   Realtime Database -> Rules
   ثم الصق محتوى ملف firebase-rules-admin-employee.json واضغط Publish.

3) إنشاء حساب المدير:
   Firebase Console -> Authentication -> Users -> Add user
   اكتب بريد المدير وكلمة المرور.

4) بعد إنشاء الحساب، انسخ UID الخاص بالمدير.

5) افتح Realtime Database -> Data
   وأضف هذا المسار:

   admins
     UID_المدير : true

مثال:
{
  "admins": {
    "abc123UID": true
  }
}

6) إضافة موظف للنشر فقط:
   أنشئ حسابًا في Authentication.
   انسخ UID.
   أضفه تحت employees:

{
  "employees": {
    "employeeUID": true
  }
}

النتيجة:
- المدير: قراءة + نشر + تعديل + حذف.
- الموظف: نشر فقط.
- الزائر العادي: قراءة المنشورات من الصفحة الرئيسية فقط.
