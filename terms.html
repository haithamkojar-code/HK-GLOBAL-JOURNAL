3. حسابات الكتّاب

لا يمكن إنشاء حساب كاتب إلا من خلال رابط دعوة يصدره المدير. يجب على الكاتب استخدام البريد الإلكتروني نفسه الموجود في الدعوة.

يلتزم الكاتب بما يلي:

  • تقديم اسم وبريد صحيحين عند التسجيل.
  • الحفاظ على سرية كلمة المرور وعدم مشاركتها مع أي شخص.
  • عدم استخدام حساب شخص آخر أو انتحال شخصية أي فرد أو جهة.
  • إبلاغ الإدارة عند الاشتباه بأي اختراق أو استخدام غير مصرح به للحساب.
  • قراءة وقبول عقد مسؤولية الكاتب قبل نشر المقالات.

يحق للإدارة تعليق أو تعطيل أي حساب كاتب عند وجود مخالفة لهذه الشروط أو عند وجود خطر أمني أو قانوني أو تحريري.

4. نشر المحتوى

كل مقال أو نص أو عنوان أو صورة أو رابط أو مصدر ينشره الكاتب من حسابه يعتبر محتوى مرتبطًا بذلك الكاتب.

يقر الكاتب بأنه المسؤول عن المحتوى المنشور تحت اسمه، ويجب أن يتأكد من أن المحتوى لا يخالف القانون أو حقوق الآخرين أو قواعد المنصة.

عند نشر معلومات مهمة أو حساسة، مثل الأخبار السياسية أو الاقتصادية أو الصحية أو القانونية، يجب على الكاتب استخدام مصادر موثوقة وتجنب التضليل أو الادعاءات غير المثبتة.

الآراء والتحليلات المنشورة باسم الكاتب تمثل رأي الكاتب ولا تعبر بالضرورة عن رأي إدارة HK Global Blog.

5. الاستخدامات والمحتويات الممنوعة

يمنع استخدام الموقع أو حساب الكاتب لأي من الأغراض التالية:

  • نشر محتوى غير قانوني أو مخالف للقوانين المعمول بها.
  • نشر خطاب كراهية أو تحريض على العنف أو التمييز.
  • التشهير أو الإساءة أو التهديد أو الابتزاز.
  • نشر معلومات شخصية عن الآخرين دون إذن أو أساس قانوني.
  • انتهاك حقوق النشر أو العلامات التجارية أو حقوق الملكية الفكرية.
  • نشر محتوى مضلل عمدًا أو أخبار كاذبة أو مصادر غير حقيقية.
  • نشر روابط خبيثة أو احتيالية أو تؤدي إلى برمجيات ضارة.
  • نشر محتوى يستغل الأطفال أو يعرّضهم للخطر.
  • استخدام الموقع لإعلانات مخفية أو ترويج تجاري دون موافقة الإدارة.
  • محاولة اختراق الموقع أو تعطيله أو الوصول غير المصرح به إلى بياناته.
عند وجود شك في قانونية أو حساسية محتوى معين، يجب عدم نشره قبل الرجوع إلى الإدارة.

قد تتخذ الإدارة إجراءات مثل:

  • تصحيح أخطاء لغوية أو تنسيقية.
  • تعديل عنوان أو ملخص لتحسين الوضوح دون تغيير المعنى الأساسي.
  • إخفاء مقال مؤقتًا للمراجعة.
  • حذف مقال مخالف.
  • تعطيل حساب كاتب عند المخالفة الخطيرة أو المتكررة.

إذا وصل بلاغ عن محتوى غير قانوني أو منتهك للحقوق، قد تقوم الإدارة بمراجعة المحتوى واتخاذ إجراء مناسب، وقد تتواصل مع الكاتب لطلب توضيح أو مصدر أو تعديل.
