1. التعريفات

لأغراض هذا العقد، يقصد بالمصطلحات التالية المعاني الموضحة أدناه:

  • المنصة: HK Global Blog، وتشمل الموقع الإلكتروني وصفحات النشر والإدارة والمقالات والسياسات المرتبطة به.
  • الإدارة: الشخص أو الجهة المسؤولة عن تشغيل HK Global Blog وإدارة حسابات الكتّاب والمحتوى المنشور.
  • الكاتب: أي شخص يحصل على دعوة من الإدارة لإنشاء حساب كاتب ونشر محتوى داخل المنصة.
  • المحتوى: أي نص أو مقال أو عنوان أو صورة أو رابط أو مصدر أو تعليق أو مادة يضيفها الكاتب داخل المنصة.
  • الحساب: حساب الكاتب المرتبط ببريده الإلكتروني ومعرّف المستخدم UID داخل Firebase Authentication وRealtime Database.

2. حساب الكاتب

يتم إنشاء حساب الكاتب من خلال رابط دعوة خاص يصدره المدير. يجب على الكاتب استخدام نفس البريد الإلكتروني الموجود في الدعوة.

يلتزم الكاتب بالحفاظ على بيانات الدخول الخاصة به وعدم مشاركة كلمة المرور أو رابط الدعوة أو الحساب مع أي شخص آخر.

أي نشاط يتم من حساب الكاتب يعتبر صادراً عن الكاتب نفسه ما لم يثبت وجود اختراق أو استخدام غير مصرح به، ويجب إبلاغ الإدارة فورًا عند الاشتباه بأي مشكلة أمنية.

3. مسؤولية الكاتب عن المحتوى

يقر الكاتب بأنه المسؤول الأول عن كل محتوى ينشره أو يحفظه أو يرسله من حسابه داخل HK Global Blog.

يلتزم الكاتب بأن يكون المحتوى المنشور:

  • غير مخالف للقانون.
  • غير مضلل أو احتيالي أو مزيف عمدًا.
  • لا ينتهك حقوق الغير أو خصوصيتهم.
  • لا يحتوي على تشهير أو إساءة أو اتهامات غير مثبتة.
  • لا ينتهك حقوق النشر أو العلامات التجارية.
  • يعتمد على مصادر موثوقة عند ذكر معلومات حساسة أو ادعاءات مهمة.

عند نشر رأي أو تحليل، يجب أن يكون واضحًا أنه رأي أو تحليل، وليس خبرًا مؤكدًا أو معلومة رسمية إذا لم يكن هناك مصدر واضح.

4. المحتوى الممنوع

يمنع على الكاتب نشر أي محتوى يتضمن أو يشجع أو يروج لأي مما يلي:

  • محتوى غير قانوني حسب قوانين الدولة أو قوانين الاتحاد الأوروبي عند التطبيق.
  • خطاب كراهية أو تحريض على العنف أو التمييز ضد الأفراد أو الجماعات.
  • تهديد أو ابتزاز أو إساءة شخصية أو تشهير.
  • معلومات شخصية عن أشخاص آخرين دون إذن واضح.
  • صور أو مواد محمية بحقوق نشر دون ترخيص أو إذن.
  • معلومات طبية أو قانونية أو مالية حساسة بصيغة نصيحة متخصصة دون مؤهل أو مصدر مناسب.
  • روابط خبيثة أو احتيالية أو مضللة أو تؤدي إلى برمجيات ضارة.
  • محتوى جنسي صريح أو استغلالي أو مخالف لسياسة المنصة.
  • محتوى يسيء للأطفال أو يستغلهم أو يعرضهم للخطر.
  • انتحال شخصية أو نشر محتوى باسم شخص آخر دون إذنه.
عند وجود شك في قانونية أو حساسية المحتوى، يجب على الكاتب عدم نشره قبل الرجوع إلى الإدارة.

5. حقوق النشر والملكية الفكرية

يلتزم الكاتب بعدم استخدام مقالات أو صور أو شعارات أو مواد محمية بحقوق نشر إلا إذا كان لديه حق قانوني أو ترخيص واضح لاستخدامها.

إذا استخدم الكاتب مصادر خارجية، يجب عليه ذكر المصدر بطريقة واضحة ومناسبة داخل المقال أو في خانة المصدر.

يحتفظ الكاتب بحقوقه الفكرية على النصوص التي يكتبها، لكنه يمنح HK Global Blog حق عرض المحتوى داخل المنصة ونشره وتنسيقه وتعديله لغويًا أو فنيًا بما لا يغير المعنى الأساسي.

تتحمل الإدارة حق إزالة أي محتوى إذا وصلها بلاغ معتبر بوجود انتهاك لحقوق النشر أو العلامة التجارية أو الخصوصية.

6. الخصوصية والبيانات الشخصية

يوافق الكاتب على أن تقوم المنصة بحفظ بيانات ضرورية لإدارة الحساب والمسؤولية التحريرية، مثل:

  • الاسم الذي يقدمه الكاتب.
  • البريد الإلكتروني.
  • معرّف المستخدم UID.
  • تاريخ قبول العقد والشروط.
  • نسخة الشروط المقبولة.
  • اسم الكاتب المرتبط بكل مقال ينشره.

تستخدم هذه البيانات لأغراض إدارة الحساب، تحديد مسؤولية المقالات، حماية المنصة، والرد على البلاغات أو النزاعات المتعلقة بالمحتوى.

يلتزم الكاتب بعدم نشر بيانات شخصية عن الآخرين دون أساس قانوني أو موافقة واضحة، خصوصًا البيانات الحساسة أو الصور الشخصية أو معلومات الاتصال أو العناوين.

يجب على الكاتب قراءة سياسة الخصوصية الخاصة بالمنصة قبل إنشاء الحساب أو نشر المحتوى.

7. حق الإدارة في مراجعة أو تعديل أو حذف المحتوى

يحق لإدارة HK Global Blog مراجعة أو تعديل أو إخفاء أو حذف أي محتوى في الحالات التالية:

  • إذا كان المحتوى مخالفًا للقانون أو سياسة المنصة.
  • إذا وصل بلاغ موثوق عن انتهاك حقوق أو خصوصية.
  • إذا كان المحتوى مضللًا أو يسبب ضررًا واضحًا للقراء أو المنصة.
  • إذا احتوى المحتوى على روابط خطرة أو مواد غير مناسبة.
  • إذا نشر الكاتب محتوى خارج نطاق المنصة أو يخالف شروط الاستخدام.

كما يحق للإدارة تعليق أو تعطيل حساب الكاتب عند وجود مخالفة خطيرة أو متكررة أو عند وجود خطر أمني أو قانوني.

8. البلاغات والشكاوى

إذا تلقّت الإدارة بلاغًا بخصوص مقال أو محتوى منشور باسم الكاتب، قد تقوم الإدارة بمراجعة المحتوى والتواصل مع الكاتب لطلب توضيح أو تعديل.

يجب على الكاتب التعاون مع الإدارة عند مراجعة البلاغات، وتقديم المصادر أو التصحيحات المطلوبة خلال مدة مناسبة.

في الحالات العاجلة أو القانونية أو المتعلقة بسلامة الأشخاص، يمكن للإدارة إخفاء المحتوى فورًا قبل التواصل مع الكاتب.

9. المصادر والدقة

يلتزم الكاتب ببذل جهد معقول للتأكد من دقة المعلومات قبل نشرها، خصوصًا في الموضوعات السياسية أو الاقتصادية أو الصحية أو القانونية أو الاجتماعية الحساسة.

عند نقل أرقام أو تصريحات أو أخبار أو اتهامات أو معلومات مهمة، يجب ذكر مصدر واضح وموثوق قدر الإمكان.

لا يجوز للكاتب تعمّد نشر معلومات يعلم أنها غير صحيحة أو مضللة أو منسوبة إلى مصدر غير حقيقي.

10. المحتوى الطبي والقانوني والمالي

إذا كتب الكاتب عن موضوع طبي أو قانوني أو مالي، يجب أن يكون واضحًا أن المحتوى معلومات عامة وليس نصيحة متخصصة.

يجب توجيه القارئ إلى الرجوع إلى طبيب أو محامٍ أو مستشار مالي مؤهل عند الحاجة، وعدم تقديم وعود أو ضمانات أو تعليمات قد تسبب ضررًا.

11. تضارب المصالح والإعلانات

إذا كان للكاتب مصلحة شخصية أو مالية في موضوع يكتب عنه، يجب توضيح ذلك للإدارة، وقد تطلب الإدارة توضيحًا داخل المقال.

لا يجوز نشر إعلان أو ترويج مدفوع أو رابط تسويقي باسم مقال عادي دون موافقة الإدارة وتوضيح مناسب للقارئ.

12. اللغة والأسلوب

يلتزم الكاتب باستخدام لغة محترمة وواضحة، وتجنب الإهانات الشخصية أو العبارات العنصرية أو التحريضية أو المهينة.

يحق للإدارة تعديل الأخطاء اللغوية أو التنسيقية أو العناوين أو الملخصات بما يحافظ على جودة المنصة دون تغيير جوهر رأي الكاتب.

13. مدة العقد وإنهاء الحساب

يبدأ هذا العقد عند موافقة الكاتب عليه أثناء التسجيل أو استخدام حساب الكاتب لنشر المحتوى.

يحق للكاتب طلب تعطيل حسابه أو حذف بياناته وفق سياسة الخصوصية والقوانين المعمول بها، مع مراعاة أن بعض البيانات قد تُحفظ لمدة ضرورية لأغراض قانونية أو أمنية أو إثبات المسؤولية عن المحتوى المنشور سابقًا.

يحق للإدارة تعطيل الحساب عند مخالفة هذا العقد أو شروط الاستخدام أو عند وجود خطر على المنصة أو المستخدمين.

14. حدود مسؤولية المنصة

لا تتحمل HK Global Blog المسؤولية عن الآراء الشخصية التي ينشرها الكاتب باسمه، ولا عن أي ضرر ينتج عن مخالفة الكاتب للقانون أو حقوق الغير أو شروط المنصة.

تحتفظ الإدارة بحق اتخاذ إجراءات مناسبة لحماية المنصة والقراء، لكن ذلك لا يعني ضمان مراجعة كل محتوى قبل نشره.

15. تعديل العقد

يحق للإدارة تحديث هذا العقد من وقت لآخر، خاصة عند تغيير طريقة عمل المنصة أو القوانين أو سياسات النشر.

عند وجود تحديث مهم، قد تطلب الإدارة من الكاتب الموافقة على النسخة الجديدة قبل الاستمرار في استخدام حساب الكاتب.

16. الإقرار النهائي

بإنشاء حساب كاتب أو تسجيل الدخول أو نشر مقال داخل HK Global Blog، يقر الكاتب بأنه قرأ هذا العقد وفهمه ووافق عليه، ويتحمل مسؤولية المحتوى الذي ينشره تحت اسمه.
