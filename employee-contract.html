1. التعريفات

  • المنصة: VORQ Blog وجميع صفحاتها الخاصة بالمقالات والنشر والإدارة.
  • المشغّل: Haitham Kojar – VORQ Digital.
  • الإدارة: الشخص أو الجهة المسؤولة عن تشغيل المدونة وإدارة حسابات الكتّاب.
  • الكاتب: أي شخص يحصل على دعوة من الإدارة لإنشاء حساب ونشر محتوى.
  • المحتوى: أي نص أو عنوان أو صورة أو رابط أو مصدر أو معلومة يضيفها الكاتب.
  • الحساب: حساب الكاتب المرتبط بالبريد الإلكتروني ومعرّف المستخدم UID.

2. حساب الكاتب

يتم إنشاء حساب الكاتب من خلال رابط دعوة خاص يصدره المدير. يجب على الكاتب استخدام البريد الإلكتروني نفسه الموجود في الدعوة، وعدم مشاركة رابط الدعوة أو بيانات الدخول مع أي شخص آخر.

أي نشاط يتم من حساب الكاتب، بما في ذلك إنشاء مقال أو تعديله أو نشره أو إضافة مصدر أو رابط، يُعد مرتبطًا بذلك الحساب ما لم يثبت وجود استخدام غير مصرح به.

3. مسؤولية الكاتب عن المحتوى

يقر الكاتب بأنه المسؤول الأول عن كل محتوى ينشره أو يحفظه أو يرسله من حسابه داخل VORQ Blog.

  • يجب أن يكون المحتوى غير مخالف للقانون.
  • يجب ألا يكون مضللًا أو احتياليًا أو مزيفًا عمدًا.
  • يجب ألا ينتهك حقوق الغير أو خصوصيتهم أو سمعتهم.
  • يجب ألا يتضمن تشهيرًا أو اتهامات خطيرة دون أساس موثوق.
  • يجب ذكر مصادر موثوقة عند عرض معلومات حساسة أو ادعاءات مهمة.
  • يجب توضيح أن المقالات الطبية أو القانونية أو المالية أو الاستثمارية هي معلومات عامة وليست نصيحة مهنية.

4. المحتوى الممنوع

  • المحتوى غير القانوني أو الذي يحرض على العنف أو الكراهية أو التمييز.
  • التهديد أو الابتزاز أو التشهير أو الإساءة الشخصية.
  • نشر بيانات شخصية عن الآخرين دون إذن واضح.
  • استخدام مواد محمية بحقوق نشر دون إذن أو ترخيص أو أساس قانوني مناسب.
  • الروابط الخبيثة أو الاحتيالية أو المضللة.
  • انتحال شخصية أو نشر محتوى باسم شخص آخر دون إذنه.
  • الإعلانات المخفية أو الترويج المدفوع دون موافقة الإدارة وتوضيح مناسب للقارئ.
عند وجود شك في قانونية أو حساسية المحتوى، يجب عدم نشره قبل الرجوع إلى الإدارة.

5. حقوق النشر والملكية الفكرية

يلتزم الكاتب بعدم استخدام مقالات أو صور أو شعارات أو مواد مملوكة للغير إلا إذا كان لديه حق قانوني أو ترخيص واضح أو كان الاستخدام مسموحًا قانونيًا.

إذا استخدم الكاتب مصادر خارجية، يجب ذكر المصدر بوضوح عند الحاجة. يحتفظ الكاتب بحقوقه على النصوص التي يكتبها، لكنه يمنح VORQ Blog وHaitham Kojar – VORQ Digital حق عرض المحتوى داخل المنصة ونشره وتنسيقه وتعديله لغويًا أو فنيًا بما لا يغير المعنى الأساسي.

6. الخصوصية والبيانات الشخصية

يوافق الكاتب على حفظ بيانات ضرورية لإدارة الحساب والمسؤولية التحريرية مثل الاسم، البريد الإلكتروني، UID، تاريخ قبول العقد، نسخة الشروط المقبولة، واسم الكاتب المرتبط بكل مقال.

تُستخدم هذه البيانات لإدارة الحساب، تحديد مسؤولية المقالات، حماية المنصة، الرد على البلاغات أو النزاعات المتعلقة بالمحتوى، وتطبيق شروط الاستخدام وسياسة الخصوصية.

7. حق الإدارة في مراجعة أو تعديل أو حذف المحتوى

يحق لإدارة VORQ Blog مراجعة أو تعديل أو إخفاء أو حذف أي محتوى إذا كان مخالفًا للقانون أو سياسة المنصة، أو وصل بلاغ معتبر، أو كان مضللًا، أو يحتوي على روابط خطرة، أو يسبب خطرًا قانونيًا أو أمنيًا أو أخلاقيًا على المنصة أو المستخدمين.

لا يعني وجود حق المراجعة أن الإدارة توافق مسبقًا على كل مقال أو تضمن دقته أو اكتماله. المقالات المنشورة باسم الكاتب تبقى تحت مسؤوليته التحريرية والقانونية.

8. البلاغات والشكاوى

إذا تلقت الإدارة بلاغًا بخصوص مقال منشور باسم الكاتب، قد تراجع المحتوى وتتواصل مع الكاتب لطلب توضيح أو تعديل أو مصادر إضافية. يجب على الكاتب التعاون بشكل معقول مع طلبات المراجعة.

9. المصادر والدقة

يلتزم الكاتب ببذل جهد معقول للتأكد من دقة المعلومات قبل نشرها، خصوصًا في الموضوعات السياسية أو الاقتصادية أو الصحية أو القانونية أو الاجتماعية الحساسة.

10. مدة العقد وإنهاء الحساب

يبدأ هذا العقد عند موافقة الكاتب عليه أثناء التسجيل أو عند استخدام حساب الكاتب لنشر المحتوى. يحق للإدارة تعطيل الحساب أو تقييد الصلاحيات عند مخالفة العقد أو عند وجود خطر على المنصة أو المستخدمين.
