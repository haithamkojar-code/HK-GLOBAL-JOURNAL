1. بيانات المالك والمشغّل

يتم تشغيل VORQ Blog من قبل VORQ Group. تستخدم هذه الصفحة البريد الإلكتروني والعنوان المذكورين أعلاه للتواصل القانوني والإداري المتعلق بالموقع.

إذا تم تسجيل كيان قانوني رسمي أو إضافة رقم منظمة / رقم ضريبي / ترخيص مستقبلاً، سيتم تحديث هذه الصفحة والصفحات القانونية المرتبطة بها.

2. طبيعة الموقع

VORQ Blog منصة تدوين ونشر أفكار وتحليلات ومقالات شخصية أو تحريرية حول المجتمع، الاقتصاد، السياسة، الأسرة، الثقافة، الحياة، والتكنولوجيا.

المدونة ليست وكالة أنباء، وليست منصة إخبارية رسمية، وليست جهة حكومية أو قانونية أو مالية أو طبية. المحتوى المنشور مخصص للقراءة العامة والمناقشة والتفكير ولا يعتبر نصيحة مهنية.

3. مسؤولية المحتوى

المقالات المنشورة باسم كاتب معين تعبر عن رأي الكاتب ومسؤوليته، ولا تعبر بالضرورة عن رأي VORQ Group أو إدارة VORQ Blog.

يلتزم الكاتب بعدم نشر محتوى غير قانوني أو مضلل أو منتهك للحقوق أو الخصوصية. تحتفظ الإدارة بحق مراجعة أو إخفاء أو حذف المحتوى المخالف أو الذي يشكل خطراً قانونياً أو أمنياً أو أخلاقياً على المنصة.

4. الروابط الخارجية

قد تحتوي المقالات على روابط خارجية لمواقع أو مصادر لا تملكها VORQ Group. وجود رابط خارجي لا يعني ضمان محتوى ذلك الموقع أو الموافقة عليه.

عند فتح رابط خارجي، يخضع المستخدم لشروط وسياسة الخصوصية الخاصة بالموقع الخارجي.

5. حقوق النشر والملكية الفكرية

جميع النصوص والتصاميم والعناصر التي تنشئها VORQ Blog أو VORQ Group محمية بحقوق الملكية الفكرية ما لم يذكر خلاف ذلك.

يجب على الكتّاب عدم نشر صور أو نصوص أو شعارات أو ملفات مملوكة للغير دون حق قانوني أو ترخيص أو إذن مناسب. يمكن لأصحاب الحقوق التواصل معنا لطلب مراجعة أي محتوى يعتقدون أنه ينتهك حقوقهم.

6. الخصوصية والبيانات الشخصية

عند استخدام الموقع أو إنشاء حساب كاتب، قد تتم معالجة بيانات مثل الاسم، البريد الإلكتروني، معرّف الحساب، بيانات المقالات، وسجلات تقنية ضرورية للتشغيل والأمان.

لمزيد من التفاصيل حول البيانات، مدة الحفظ، وحقوق المستخدمين، يرجى قراءة سياسة الخصوصية.

7. القانون المعمول به وحل النزاعات

يخضع استخدام الموقع للقوانين المعمول بها في السويد والاتحاد الأوروبي حسب طبيعة الاستخدام ومكان المستخدم والالتزامات القانونية ذات الصلة.

قبل أي إجراء رسمي، يُفضّل التواصل معنا عبر البريد الإلكتروني لمحاولة حل المشكلة بشكل مباشر وهادئ.

8. التواصل والبلاغات
