2. البيانات التي قد نجمعها

تختلف البيانات حسب طريقة استخدام الموقع. الزائر العادي لا يحتاج إلى إنشاء حساب لقراءة المقالات، أما الكاتب فيحتاج إلى حساب مخصص للنشر.

نوع المستخدم البيانات المحتملة سبب الاستخدام
الزائر قد تتم معالجة بيانات تقنية أساسية مثل معلومات المتصفح أو الجهاز أو سجلات تقنية عند الاستضافة. عرض الموقع، تحسين الأمان، اكتشاف الأخطاء، ومنع إساءة الاستخدام.
الكاتب الاسم، البريد الإلكتروني، UID، حالة الحساب، تاريخ قبول الشروط، نسخة الشروط المقبولة، والمقالات المنشورة. إنشاء حساب الكاتب، تحديد مسؤولية المقالات، إدارة المحتوى، وحماية المنصة.
المدير البريد الإلكتروني، UID، صلاحية المدير، وسجلات إنشاء دعوات الكتّاب. إدارة المنصة، إنشاء الدعوات، ومراقبة الصلاحيات.
المقالات عنوان المقال، المحتوى، التصنيف، اللغة، اسم الكاتب، بريد الكاتب، UID الكاتب، تاريخ النشر والتحديث. عرض المقالات للزوار، حفظ نسب المقال للكاتب، وإدارة المحتوى.

3. لماذا نستخدم البيانات؟

  • تشغيل الموقع وعرض المقالات للزوار.
  • إنشاء وتفعيل حسابات الكتّاب.
  • حفظ اسم الكاتب مع المقال المنشور.
  • إدارة صلاحيات المدير والكتّاب.
  • حماية الموقع من الاستخدام غير المصرح به.
  • التعامل مع البلاغات أو الشكاوى المتعلقة بالمحتوى.
  • إثبات قبول الكاتب للعقد والشروط وسياسة الخصوصية وإخلاء المسؤولية.
  • تحسين جودة المحتوى وإدارة المقالات المنشورة أو المسودات.

4. Firebase والخدمات التقنية

يستخدم الموقع Firebase لتشغيل بعض وظائفه، مثل تسجيل الدخول، إنشاء حسابات الكتّاب، حفظ بيانات الدعوات، وحفظ المقالات.

  • Firebase Authentication: لتسجيل الدخول وإنشاء حسابات البريد وكلمة المرور.
  • Firebase Realtime Database: لحفظ بيانات المقالات، الكتّاب، المدير، والدعوات.
  • Firebase Hosting: لاستضافة صفحات الموقع عند النشر النهائي على Firebase.

داخل قاعدة البيانات قد تظهر مسارات تقنية مثل:

  • admins لحسابات المدير.
  • employees لحسابات الكتّاب تقنيًا.
  • employeeInvites لدعوات الكتّاب تقنيًا.
  • posts للمقالات.
  • users لبيانات الحسابات.
كلمة employees داخل قاعدة البيانات هي اسم تقني فقط، أما الاسم الظاهر للمستخدمين في الموقع فهو الكتّاب.

5. الأساس القانوني لاستخدام البيانات

بحسب طبيعة الاستخدام، قد تعتمد معالجة البيانات على واحد أو أكثر من الأسس التالية:

  • تنفيذ العلاقة مع الكاتب: عندما ينشئ الكاتب حسابًا ويستخدم المنصة لنشر المقالات.
  • الموافقة: عندما يوافق الكاتب صراحة على عقد مسؤولية الكاتب وشروط الاستخدام وسياسة الخصوصية وإخلاء المسؤولية.
  • المصلحة المشروعة: لحماية الموقع، منع إساءة الاستخدام، إدارة المحتوى، وتوثيق مسؤولية المقالات.
  • الالتزام القانوني: إذا أصبح من الضروري حفظ أو تقديم بعض البيانات استجابة لالتزام قانوني أو بلاغ رسمي.

6. مدة حفظ البيانات

يتم حفظ البيانات فقط للمدة اللازمة لتحقيق الأغراض الموضحة في هذه السياسة، أو للمدة التي تتطلبها القوانين المعمول بها.

  • بيانات حساب الكاتب تبقى محفوظة طالما أن الحساب فعال أو طالما توجد حاجة لإثبات مسؤولية المحتوى المنشور.
  • بيانات المقالات تبقى محفوظة طالما أن المقال موجود على الموقع أو مطلوب لأغراض الأرشفة أو النزاعات.
  • بيانات قبول الشروط قد تبقى محفوظة لإثبات أن الكاتب وافق على السياسات قبل النشر.
  • الدعوات غير المستخدمة أو القديمة يمكن حذفها أو تعطيلها من قبل الإدارة.

7. حقوق المستخدمين والكتّاب

وفقًا للقوانين المعمول بها، قد يكون للمستخدم أو الكاتب حقوق تتعلق ببياناته الشخصية، مثل:

  • طلب معرفة البيانات المحفوظة عنه.
  • طلب تصحيح بيانات غير صحيحة.
  • طلب حذف بياناته عندما لا يوجد سبب قانوني أو تشغيلي للاحتفاظ بها.
  • طلب تقييد معالجة بياناته في حالات معينة.
  • الاعتراض على معالجة معينة إذا كان لديه سبب مشروع.
  • طلب نسخة من بياناته بصيغة مناسبة عندما يكون ذلك قابلًا للتطبيق.
  • تقديم شكوى إلى جهة حماية البيانات المختصة إذا كان يعتقد أن بياناته عولجت بطريقة غير قانونية.
بعض الطلبات قد لا تؤدي إلى حذف كل البيانات فورًا إذا كانت هناك حاجة قانونية أو أمنية أو تحريرية للاحتفاظ بجزء منها، مثل إثبات مسؤولية مقال منشور سابقًا.

8. حماية البيانات

نستخدم وسائل تقنية وتنظيمية معقولة لحماية البيانات، مثل:

  • استخدام Firebase Authentication لتسجيل الدخول.
  • استخدام قواعد صلاحيات داخل Firebase Realtime Database.
  • تقسيم الصلاحيات بين المدير والكتّاب.
  • إخفاء صفحات الإدارة عن الفهرسة باستخدام noindex.
  • تقليل البيانات المحفوظة إلى ما هو ضروري لتشغيل المنصة.

رغم ذلك، لا توجد وسيلة إلكترونية آمنة بنسبة 100%. لذلك يجب على الكاتب اختيار كلمة مرور قوية وعدم مشاركتها مع أي شخص.

9. مشاركة البيانات مع أطراف أخرى

لا نبيع بيانات المستخدمين أو الكتّاب. قد تتم معالجة بعض البيانات من خلال خدمات تقنية ضرورية لتشغيل الموقع، مثل خدمات الاستضافة وقاعدة البيانات وتسجيل الدخول.

  • عند وجود طلب قانوني صحيح.
  • لحماية حقوق الموقع أو سلامة المستخدمين.
  • للتحقيق في إساءة استخدام أو اختراق أو محتوى غير قانوني.
  • مع مزود خدمة تقني ضروري لتشغيل الموقع.

10. الروابط الخارجية

قد تحتوي المقالات أو صفحات الموقع على روابط خارجية. لا تتحمل VORQ Blog مسؤولية سياسات الخصوصية أو محتوى المواقع الخارجية.

عند فتح رابط خارجي، يجب على المستخدم قراءة سياسة الخصوصية الخاصة بذلك الموقع.

11. ملفات تعريف الارتباط والتخزين المحلي

قد تستخدم بعض الخدمات التقنية ملفات تعريف ارتباط أو تخزينًا محليًا أو وسائل مشابهة لتسجيل الدخول أو حفظ الجلسة أو تحسين الأمان.

إذا تمت إضافة أدوات تحليل أو إعلانات أو تتبع مستقبلًا، يجب تحديث هذه السياسة وذكر نوع الأداة والغرض منها وطريقة التحكم بها.

12. خصوصية الأطفال

الموقع مخصص للمقالات العامة وليس مخصصًا للأطفال كمنصة تسجيل أو نشر. لا يجب إنشاء حساب كاتب للأطفال أو جمع بياناتهم دون أساس قانوني واضح وموافقة مناسبة من ولي الأمر عند الحاجة.

يمنع نشر بيانات أو صور أطفال أو معلومات قد تعرضهم للخطر دون موافقة وأساس قانوني مناسب.

13. مسؤولية الكاتب تجاه بيانات الآخرين

يلتزم الكاتب بعدم نشر بيانات شخصية عن أشخاص آخرين دون إذن أو أساس قانوني واضح.

  • الأسماء الكاملة إذا كانت مرتبطة باتهامات أو معلومات حساسة.
  • العناوين وأرقام الهواتف والبريد الإلكتروني.
  • الصور الشخصية أو صور الأطفال.
  • المعلومات الصحية أو المالية أو القانونية.
  • أي معلومات قد تكشف هوية شخص في سياق حساس.

14. تحديث سياسة الخصوصية

قد يتم تحديث هذه السياسة عند تغيير طريقة عمل الموقع أو إضافة خدمات جديدة أو تعديل القوانين أو السياسات الداخلية.

عند وجود تغيير مهم، قد يتم إشعار الكتّاب أو طلب الموافقة على النسخة الجديدة قبل الاستمرار في استخدام حساب الكاتب.
