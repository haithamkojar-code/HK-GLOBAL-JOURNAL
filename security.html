1. طريقة الإبلاغ

أرسل تفاصيل الثغرة إلى info@vorq.group مع عنوان واضح مثل: Security report - VORQ Blog. يمكن الاتصال هاتفيًا على 0178-3705133 باللغة العربية فقط للتنبيه، لكن تفاصيل الثغرة يجب أن ترسل كتابيًا.

يرجى ذكر رابط الصفحة، خطوات إعادة المشكلة، التأثير المتوقع، ولقطات شاشة إن وجدت دون كشف بيانات مستخدمين.

2. النطاق المسموح

  • إبلاغ نظري أو اختبار محدود على حسابك فقط.
  • مشاكل XSS أو صلاحيات أو إعدادات Firebase التي يمكن شرحها دون استغلال واسع.
  • روابط عامة تخص VORQ Blog فقط.

3. الممنوع

  • الوصول إلى بيانات أو حسابات غير مملوكة لك.
  • تحميل زائد أو DoS أو تعطيل الخدمة.
  • نشر الثغرة علنًا قبل إتاحة وقت معقول للمعالجة.
  • استخدام أدوات آلية كثيفة ضد الموقع.

4. المعالجة

لا يوجد برنامج مكافآت مالي حاليًا. سنراجع البلاغات الجادة ونحاول معالجة المشاكل حسب الأولوية والخطورة.
